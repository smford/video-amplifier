Engineered for 24/7 Production Reliability

Built from the ground up for high-availability home automation, commercial NVRs, and air-gapped security networks.

⚡

Zero Transcode Fan-Out

Multiplexes pure RTP packets and JPEG frames directly from upstream without CPU-heavy software re-encoding, preserving native video quality and microsecond latency.

🌐

Native WebRTC (WHEP) Egress

Standard WHEP HTTP SDP offer exchange enables sub-second (50-150ms) hardware-accelerated video playback directly in modern desktop and mobile browsers.

🔄

Synthetic Keep-Alives

Maintains active downstream NVR sessions (Frigate, Blue Iris, Home Assistant) during transient camera reboots or Wi-Fi dropouts by injecting synthetic keep-alives.

🛡️

GOP-Aware Backpressure Eviction

Isolates slow viewers on poor wireless links. Drops non-reference frames dynamically before triggering clean keyframe resynchronization, eliminating video tearing.

🔒

Granular RBAC Security

Configure declarative users with scoped permissions by camera and action (snapshot, mjpeg, rtsp, whep, fmp4). Clean 401/403 status codes prevent browser login loops.

🔍

ONVIF WS-Discovery Scanner

Built-in multicast probe command (video-amplifier scan) auto-detects ONVIF IP cameras on your local subnet and reveals their RTSP streaming endpoints.

⏪

Instant Pre-Roll DVR Clips

Maintains a rolling in-memory 20-30s circular GOP buffer. Instantly download standalone MP4 pre-roll clips (/cameras/{id}/clip.mp4) when motion events trigger.

📊

Prometheus & Grafana Ready

Exports detailed telemetry on port :9090 (bitrate, fps, consumer lag, drops). Comes with a pre-configured Grafana dashboard and Docker Compose stack.

📱

Self-Contained Dashboard UI

Zero-dependency, air-gapped web interface featuring live video feeds, one-click copyable stream URL chips, and live connection telemetry.

Quickstart in Under 60 Seconds

Run locally as a single static binary or deploy using the official Docker container.

bash • install & run 
# 1. Clone and compile with pure Go
git clone https://github.com/smford/video-amplifier.git
cd video-amplifier
make build

# 2. Discover ONVIF IP cameras on your local network
./video-amplifier scan

# 3. Generate a production-ready starter configuration
./video-amplifier init

# 4. Start the proxy
./video-amplifier -config config.yaml

Downstream Protocol Endpoints

A unified endpoint interface for browsers, media players, and NVRs.

Protocol Method Path Description
Web Dashboard GET /, /ui, /dashboard Responsive dark-mode live multi-camera monitoring UI
WebRTC POST /cameras/{id}/whep Standard WHEP SDP exchange for ultra-low latency browser playback
RTSP Relay DESCRIBE/PLAY rtsp://<host>:8554/{id} Zero-copy RTSP stream with timed ONVIF XML metadata forwarding
MJPEG GET /cameras/{id}/mjpeg Multipart HTTP MJPEG stream (multipart/x-mixed-replace)
Snapshot GET /cameras/{id}/snapshot.jpg Instant cached single JPEG frame
fMP4 / MSE GET /cameras/{id}/fmp4 Fragmented MP4 stream for HTML5 <video> and MSE players
DVR Pre-Roll GET /cameras/{id}/clip.mp4 Instant downloadable MP4 containing the last 20–30s of buffered video
Prometheus GET :9090/metrics Prometheus metrics scrape target (bitrate, fps, drops, lag)
